# ปรับระบบกำหนดสิทธิ์ให้ง่ายและถูกต้อง

## ปัญหาที่พบ (ตรวจสอบจากระบบจริง)
- ตอนนี้ Admin แทบไม่ต่างจากผู้ใช้ทั่วไป: ต้องติ๊กเมนูทีละอันเหมือนกัน ต่างแค่เข้าหน้า "จัดการผู้ใช้" ได้ ทำให้ต้องตั้งค่าซ้ำซ้อนและมักตกหล่น
- Super Admin ข้ามทุกการตรวจสอบ ทั้งเมนูและฝ่าย
- การเลือกฝ่ายยังไม่บังคับ จึงมี Admin ที่ไม่เห็นข้อมูลใดเลย

## โครงใหม่ 3 ระดับ (ชัดเจน ไม่ทับกัน)

| ระดับ | เมนู | ฝ่าย/แผนก |
|---|---|---|
| **Super Admin** | ทุกเมนู รวม 4 เรื่องที่สงวนไว้ | ทุกฝ่าย |
| **Admin** | ทุกเมนูงาน (อัตโนมัติ ไม่ต้องติ๊ก) ยกเว้น 4 เรื่องที่สงวน | เฉพาะฝ่ายที่กำหนดให้ |
| **ผู้ใช้ทั่วไป** | เลือกตามหน้าที่งาน (Duty) + สิทธิ์ผู้อนุมัติ เหมือนเดิม | เฉพาะฝ่ายที่กำหนดให้ |

### 4 เรื่องที่สงวนให้ Super Admin เท่านั้น
1. จัดการผู้ใช้และสิทธิ์
2. นำเข้าข้อมูลเริ่มต้น (Import ตั้งต้น)
3. ทดสอบระบบ + คู่มือฐานข้อมูล
4. แก้ไขข้อความคู่มือแนวทางสิทธิ์ (Roles/Functions)

## การใช้งานใน Wizard
- ขั้นที่ 1 เพิ่มตัวเลือกระดับผู้ใช้ด้านบนสุด: ผู้ใช้ทั่วไป / Admin / Super Admin
  - เลือก **Admin** → ส่วน "หน้าที่งาน" และ "สิทธิ์ผู้อนุมัติ" ถูกซ่อน แทนที่ด้วยกล่องสรุปว่า "ได้ทุกเมนูงานในฝ่ายที่กำหนด (ยกเว้น 4 เรื่องที่สงวน)"
  - เลือก **Super Admin** → ซ่อนทั้งหน้าที่งานและขั้นเลือกฝ่าย พร้อมข้อความว่าเห็นทุกฝ่าย
  - เลือก **ผู้ใช้ทั่วไป** → ทำงานเหมือนปัจจุบันทุกอย่าง
- ขั้นที่ 2 (ฝ่าย/แผนก): บังคับเลือกอย่างน้อย 1 ฝ่ายสำหรับ Admin และผู้ใช้ทั่วไป ปุ่ม "ถัดไป" กดไม่ได้จนกว่าจะเลือก พร้อมข้อความเตือน
- ขั้นที่ 3 (ตรวจสอบ): กรณี Admin แสดงสรุปสั้น ๆ ว่าได้ทุกเมนู + รายชื่อฝ่าย ไม่ต้องไล่ติ๊กรายเมนู

## จุดอื่นที่ปรับตาม
- หน้ารายการผู้ใช้: ป้ายบทบาทอธิบายต่างกันชัด — Super Admin = ทุกฝ่าย, Admin = ทุกเมนู เฉพาะฝ่ายที่กำหนด
- Matrix สิทธิ์: แถวของ Admin/Super Admin แสดงเป็น "ได้ทั้งหมด" แบบอ่านอย่างเดียว ป้องกันการตั้งค่าทับกัน
- หน้าคู่มือแนวทางสิทธิ์: ปรับคำอธิบาย Super Admin และ Admin ให้ตรงกับกติกาใหม่
- เตือนเมื่อบันทึก Admin ที่ยังไม่มีฝ่าย

## รายละเอียดทางเทคนิค
- `useFunctionPermissions.hasFunctionAccess`: เพิ่ม `SUPER_ADMIN_ONLY_FNS = ["admin", "setup_import", "testing", "guide_edit"]` (map ตามชื่อฟังก์ชันจริงในระบบ — ปัจจุบันรวมอยู่ใน `admin`, จะแยกเป็นสิทธิ์ย่อยในไฟล์เดียวกัน) แล้วให้ `isAdmin` ผ่านทุกฟังก์ชันที่ไม่ได้อยู่ในลิสต์นี้; `getAccessibleFunctions` คืนรายการเดียวกัน
- `AppSidebar` และหน้าที่เช็ก `hasFunctionAccess` ไม่ต้องแก้ เพราะได้ผลใหม่อัตโนมัติ
- การกรองฝ่ายยังใช้ `useDeptScope`/`useDepartmentPermissions` เดิม (bypass เฉพาะ Super Admin) — Admin จึงถูกจำกัดฝ่ายตามที่ต้องการอยู่แล้ว
- `PermissionWizard.tsx`: เพิ่ม state `accessLevel` ("user" | "admin" | "super_admin") derive จาก roles ที่โหลดมา; ตอนบันทึกกำหนด roles ผ่าน `save_user_roles` และสำหรับ Admin/Super Admin ไม่เขียนแถวใน `user_function_permissions` (ล้างของเดิมทิ้งเพื่อไม่ให้ค้าง)
- `PermissionMatrix.tsx`, `UserPermissionManager.tsx`, `RoleDescriptions.tsx`: ปรับการแสดงผลตามระดับใหม่
- ไม่มีการแก้โครงสร้างฐานข้อมูล และสิทธิ์ของผู้ใช้ทั่วไปที่ตั้งไว้แล้วไม่เปลี่ยน
