

## แผนเพิ่มตัวเลือก "รูปแบบการรับสินค้า" ในฟอร์มขอเบิก

### สิ่งที่จะทำ

**1. Database Migration** — เพิ่มคอลัมน์ `pickup_type` ในตาราง `goods_issue_pending`
- Type: `text`, default `'scheduled'`
- ค่าที่รองรับ: `scheduled` (นัดรับล่วงหน้า), `wait_onsite` (รอรับกลับทันที), `delivery` (จัดส่ง)

**2. ปรับ IssueRequest.tsx** — เพิ่ม dropdown "รูปแบบการรับสินค้า" ในส่วนข้อมูลผู้ขอเบิก
- ตัวเลือก:
  - **นัดรับล่วงหน้า** — แสดงช่องวันที่/เวลาตามปกติ
  - **รอรับที่คลัง** — ซ่อนช่องวันที่/เวลา แสดงสถานะ "รอรับกลับ" ให้เจ้าหน้าที่เห็น
  - **จัดส่ง** — แสดงช่องระบุจุดหมาย
- Logic: ช่องวันที่/เวลาจะแสดงเฉพาะเมื่อเลือก "นัดรับล่วงหน้า"
- บันทึกค่า `pickup_type` ลง DB ตอน submit

**3. ปรับ headerData state** — เพิ่ม `pickup_type: "scheduled"` เป็น default

**4. ปรับการแสดงผลในประวัติคำขอ** — แสดง Badge รูปแบบการรับ เช่น 🏪 รอรับที่คลัง / 📅 นัดรับ / 🚚 จัดส่ง

### ไฟล์ที่ต้องแก้ไข
- `src/pages/IssueRequest.tsx` — เพิ่ม dropdown + conditional logic
- DB migration — เพิ่มคอลัมน์ `pickup_type`
