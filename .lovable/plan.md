
## 🎯 Flow ที่ถูกต้อง (End-to-End Loop)

```text
[1] Master Data → เครื่องมือ
      สร้าง/แก้ไขเครื่องมือ + กำหนดรอบ PM (วัน) + ประเภท PM
                │
                ▼
[2] ตาราง PM เครื่องมือ  (/tool-pm-schedule)
      แสดง "เครื่องมือทั้งหมด" + สถานะ PM ล่าสุด
      กดปุ่ม ➕ ที่แถว = สร้างตั๋ว PM (TPM-xxxxxx)
                │  (ตั๋วเข้าคิว)
                ▼
[3] งาน PM เครื่องมือ  (/tool-pm-tasks)
      แสดงเฉพาะตั๋วที่ยัง pending / in_progress
      กด "ตรวจสอบ" → กรอกผล/รูป/หมายเหตุ → บันทึก
                │
       ┌────────┴────────┐
       ▼                 ▼
   ตั๋วปิด (completed)   บันทึกลง tool_pm_history
   → หายจากหน้านี้        → โผล่ที่ประวัติ PM
                │
                ▼
[4] ประวัติ PM เครื่องมือ  (/tool-pm-history)
      ดูรายงาน + Filter + Export Excel + ดูรูป
```

## 🐞 ปัญหาที่พบตอนนี้

1. **ปุ่ม ➕ ในหน้าตาราง PM สร้างตั๋วซ้ำได้ไม่จำกัด** — ผู้ใช้กด 3 ครั้งเลยได้ TPM-000004, 005, 006 สำหรับ TL 0001 (ค้างที่หน้างาน PM 3 ใบ) ทำให้ดูเหมือน "กดตรวจแล้วไม่หายซักที" ทั้งที่จริงเป็นคนละตั๋ว
2. หน้า **งาน PM** ไม่มีตัวกรอง (ฝ่าย/สถานะ/กำหนด) ไม่มี Export
3. หน้า **ประวัติ PM** ขาดคอลัมน์ **รูปการตรวจ** และหมายเหตุถูก truncate อ่านไม่ครบ
4. ตัวกรองประวัติยังไม่มี "ช่วงวันที่" (มีแค่ปี/เดือน)

## 🔧 แผนแก้ไข (จบในครั้งเดียว)

### A. หน้า "ตาราง PM เครื่องมือ" — กันสร้างตั๋วซ้ำ
- ปุ่ม ➕ ในแถว: ถ้ามี pending/in_progress อยู่แล้ว → **disable + tooltip** "มีตั๋ว PM ค้างอยู่แล้ว (TPM-xxxx) กรุณาตรวจให้เสร็จก่อน"
- แสดงหมายเลขตั๋วล่าสุดในคอลัมน์สถานะ เพื่อให้ผู้ใช้เห็นชัดว่าตั๋วไหนค้าง
- Confirm dialog ก่อนสร้างตั๋ว: "สร้างตั๋ว PM ใหม่สำหรับ TL 0001?"

### B. หน้า "งาน PM เครื่องมือ" — เพิ่มตัวกรอง/คอลัมน์
- เพิ่มตัวกรอง: **ฝ่าย**, **สถานะกำหนด** (เกินกำหนด / วันนี้ / ≤7 วัน / >7 วัน), **ประเภทเครื่องมือ** (ทรัพย์สินบริษัท/ประจำตัวช่าง)
- เพิ่มคอลัมน์: **ฝ่าย**, **ประเภท** (เครื่องมือประจำตัวช่าง = badge)
- ปุ่ม Export Excel
- Confirm dialog ก่อนกด "ตรวจสอบ" ให้ผู้ใช้มั่นใจว่ากดถูกตั๋ว
- แสดง toast ชัดเจนหลังบันทึก: "บันทึกผล PM สำเร็จ ตั๋ว TPM-xxxx ถูกย้ายไปประวัติแล้ว"

### C. หน้า "ประวัติ PM เครื่องมือ" — เพิ่มข้อมูลให้ครบ
- เพิ่มคอลัมน์ **📷 รูป** — icon แสดงจำนวนรูป คลิกเปิด Carousel (ใช้ `tool_pm_task_images`)
- คอลัมน์ **หมายเหตุ** — เปลี่ยนจาก truncate เป็น tooltip / expandable
- เพิ่ม **ชื่อเครื่องมือ+ยี่ห้อ** ให้เด่นขึ้น
- เพิ่มตัวกรอง **ช่วงวันที่** (Date range picker)
- Export Excel ให้รวม path/ลิงก์รูปด้วย

### D. เอกสารประกอบ
- อัปเดตกล่อง "วิธีใช้งาน" ในหน้าตาราง PM ให้อธิบาย Loop ที่ 4 ขั้น + เตือนเรื่อง "1 เครื่องมือ = 1 ตั๋วค้างเท่านั้น"
