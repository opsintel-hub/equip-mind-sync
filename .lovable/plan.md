
# แผนปรับโครงสร้างเมนูและสิทธิ์ "ภาพโฆษณา" (ฉบับแก้ไข)

## การเปลี่ยนแปลงจากแผนเดิม

แผนเดิมรวม "เบิก/จ่าย" ไว้ในหน้าเดียวสำหรับคนเดียวกัน แผนใหม่แยกเป็น **4 เมนูย่อย** ตามบทบาทจริง โดยอ้างอิงรูปแบบจากระบบ "คลังสินค้า" ที่มีอยู่แล้ว (ขอเบิกสินค้า vs จ่ายสินค้า)

---

## โครงสร้าง Sidebar ใหม่

```text
ป้ายโฆษณา (เดิม -- ลบเมนูภาพโฆษณาออก)
  ├── จัดการป้ายโฆษณา
  └── PM ป้ายโฆษณา

ภาพโฆษณา (หมวดใหม่!)
  ├── นำเข้าภาพโฆษณา      → /ad-entry       สิทธิ์: ad_entry
  ├── รับเข้าคลังภาพ       → /ad-receive     สิทธิ์: ad_warehouse
  ├── เบิกภาพโฆษณา        → /ad-request     สิทธิ์: ad_issue_request
  └── จ่ายภาพโฆษณา        → /ad-issue       สิทธิ์: ad_warehouse
```

---

## ใครทำอะไรในแต่ละเมนู

| เมนู | บทบาท | สิทธิ์ | หน้าที่ |
|------|--------|--------|---------|
| นำเข้าภาพโฆษณา | ผู้นำเข้า (Receiver) | `ad_entry` | กรอกข้อมูลภาพใหม่/ชั่วคราว/เก่า, ดูรายการทั้งหมด, จัดการ Master Data, ดู Dashboard |
| รับเข้าคลังภาพ | เจ้าหน้าที่คลัง | `ad_warehouse` | เห็นรายการรอรับ, ยืนยันรับ/ปฏิเสธ, สร้างเอกสารเบิกอัตโนมัติ |
| เบิกภาพโฆษณา | ผู้เบิก (Requester) | `ad_issue_request` | สร้างคำขอเบิกภาพ, ติดตามสถานะคำขอของตัวเอง |
| จ่ายภาพโฆษณา | เจ้าหน้าที่คลัง (คนเดียวกับรับเข้า) | `ad_warehouse` | ดูคำขอเบิกทั้งหมด, ยืนยันจ่าย, ยืนยันติดตั้งเสร็จ |

---

## สิทธิ์ใหม่ 3 รายการ

| ชื่อฟังก์ชัน | Label | คำอธิบาย |
|-------------|-------|----------|
| `ad_entry` | นำเข้าภาพโฆษณา | กรอกข้อมูลภาพโฆษณาเข้าระบบ (ภาพใหม่, ฝากชั่วคราว, ภาพเก่า) |
| `ad_issue_request` | เบิกภาพโฆษณา | สร้างคำขอเบิกภาพโฆษณา (สำหรับผู้เบิก) |
| `ad_warehouse` | คลังภาพโฆษณา | รับเข้าคลัง + จ่ายภาพโฆษณาออก (สำหรับเจ้าหน้าที่คลัง) |

สิทธิ์เหล่านี้ใช้ระบบ `user_function_permissions` เดิม (ไม่ต้องทำ Database Migration)

## ผังการทำงาน (Workflow)

```text
ผู้นำเข้า (ad_entry)              เจ้าหน้าที่คลัง (ad_warehouse)        ผู้เบิก (ad_issue_request)
       |                                    |                                  |
  กรอกข้อมูลภาพ                             |                                  |
  (สถานะ: pending)                          |                                  |
       |                                    |                                  |
       +------ รอรับเข้าคลัง ------>  ยืนยันรับเข้า                            |
       |                            (สถานะ: in_storage)                        |
       |                                    |                                  |
       |                            สร้างเอกสารเบิก                  สร้างคำขอเบิกเอง
       |                            อัตโนมัติ (กรณีภาพใหม่)                    |
       |                                    |                                  |
       |                                    +<-------- คำขอเบิก (pending) ------+
       |                                    |
       |                              ยืนยันจ่ายออก
       |                            (สถานะ: issued)
       |                                    |
       |                            ยืนยันติดตั้งเสร็จ
       |                            (สถานะ: completed)
```

## รายละเอียดทางเทคนิค

### ไฟล์ที่ต้องสร้างใหม่ (3 ไฟล์)

| ไฟล์ | คำอธิบาย |
|------|----------|
| `src/pages/AdEntry.tsx` | หน้า "นำเข้าภาพโฆษณา" -- ย้าย entry forms (AdNewForm, AdTemporaryForm, AdOldForm), AdList, AdDashboard, AdMasterDataDialog, AdDetailDialog มาจาก AdManagement.tsx |
| `src/pages/AdRequest.tsx` | หน้า "เบิกภาพโฆษณา" (ใหม่) -- มี AdIssueDialog สำหรับสร้างคำขอ + ตารางแสดงคำขอเฉพาะของผู้ใช้คนนั้น พร้อมติดตามสถานะ (รอเบิก/เบิกแล้ว/เสร็จสิ้น) |
| `src/pages/AdIssue.tsx` | หน้า "จ่ายภาพโฆษณา" -- ย้าย AdIssueList มาจาก AdManagement.tsx (แสดงคำขอทั้งหมด + ปุ่มยืนยันจ่าย/ติดตั้งเสร็จ) |

### ไฟล์ที่ต้องแก้ไข (5 ไฟล์)

| ไฟล์ | การเปลี่ยนแปลง |
|------|---------------|
| `src/pages/AdManagement.tsx` | เปลี่ยนเป็นหน้า "รับเข้าคลังภาพ" -- เหลือเฉพาะ AdReceiveSection |
| `src/components/AppSidebar.tsx` | ลบ "จัดการภาพโฆษณา" จากหมวด "ป้ายโฆษณา", เพิ่มหมวด "ภาพโฆษณา" ใหม่พร้อม 4 เมนูย่อย |
| `src/App.tsx` | เพิ่ม routes: `/ad-entry`, `/ad-receive`, `/ad-request`, `/ad-issue` + ลบ `/ad-management` |
| `src/hooks/useFunctionPermissions.tsx` | เพิ่ม `ad_entry`, `ad_issue_request`, `ad_warehouse` ใน SYSTEM_FUNCTIONS |
| `src/components/admin/FunctionDescriptions.tsx` | เพิ่มคำอธิบายฟังก์ชันใหม่ 3 รายการในหน้า Admin |

### ความแตกต่างระหว่างหน้า "เบิก" กับ "จ่าย"

**หน้าเบิก (AdRequest.tsx)** -- สำหรับผู้เบิก:
- ปุ่มสร้างคำขอเบิก (AdIssueDialog)
- ตารางแสดงเฉพาะคำขอของตัวเอง (filter by `created_by = user.id`)
- ดูสถานะได้อย่างเดียว (รอเบิก / เบิกแล้ว / เสร็จสิ้น) ไม่มีปุ่ม action

**หน้าจ่าย (AdIssue.tsx)** -- สำหรับเจ้าหน้าที่คลัง:
- เห็นคำขอเบิกทั้งหมดจากทุกคน (รวมที่สร้างอัตโนมัติ)
- ปุ่ม "ยืนยันจ่าย" (pending -> issued)
- ปุ่ม "ติดตั้งแล้ว" (issued -> completed)

### ขั้นตอนการดำเนินงาน

1. เพิ่มสิทธิ์ 3 รายการใน `useFunctionPermissions.tsx` + `FunctionDescriptions.tsx`
2. สร้าง `AdEntry.tsx` (ย้าย entry forms + list + dashboard + master data)
3. สร้าง `AdRequest.tsx` (สร้างคำขอ + ดูเฉพาะของตัวเอง)
4. สร้าง `AdIssue.tsx` (จ่ายภาพ -- คำขอทั้งหมด + ปุ่ม action)
5. แก้ `AdManagement.tsx` เป็นหน้ารับเข้าคลัง
6. แก้ `App.tsx` เพิ่ม 4 routes ใหม่ ลบ route เก่า
7. แก้ `AppSidebar.tsx` ปรับโครงสร้างเมนู

ไม่ต้องทำ Database Migration เพราะ `function_name` ในตาราง `user_function_permissions` เป็น VARCHAR จึงเพิ่มค่าใหม่ได้ทันทีจากฝั่ง Frontend
