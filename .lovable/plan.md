

# แผนปรับชื่อเมนูและลดความสับสนในหน้า Media Player

## สิ่งที่ตรวจพบ

ปัจจุบันระบบมี Media Player อยู่ 2 จุด ซึ่งทำหน้าที่ **คนละอย่าง** และไม่ซ้ำซ้อนกัน:

| จุดที่พบ | เส้นทาง | หน้าที่จริง |
|----------|---------|------------|
| เมนู "นำเข้า Media Player" ภายใต้ "รับสินค้าเข้า (GR)" | `/media-player-entry` | **จัดการ Media Player** -- สร้างใหม่, Import Excel, Dashboard, ติดตั้ง/ถอดจากป้าย |
| Toggle "Media Player" ในหน้า "นำสินค้าเข้า" | `/delivery-entry` | **ซื้อเครื่องรุ่นเดิม** ที่มีในระบบแล้ว เข้าคลังสินค้าผ่าน GR flow (Delivery -> Receive -> Stock) |

**ปัญหา**: ชื่อเมนู "นำเข้า Media Player" ทำให้ผู้ใช้สับสนว่าเป็นการ "นำสินค้าเข้า" (Delivery Entry) ทั้งที่จริงเป็นหน้าจัดการ

---

## สิ่งที่จะแก้ไข

### 1. เปลี่ยนชื่อเมนูใน Sidebar

**ก่อน**: "นำเข้า Media Player" (ฟังเหมือนนำสินค้าเข้าคลัง)
**หลัง**: "จัดการ Media Player" (ตรงกับหน้าจอจริงที่แสดงอยู่แล้ว)

### 2. ไม่จำเป็นต้องปรับอะไรเพิ่ม

สำหรับเรื่อง "นำเข้าป้ายโฆษณา" ที่ถาม -- ในหน้า "นำสินค้าเข้า" (`/delivery-entry`) เมื่อเปิด Toggle "Media Player" จะเป็นการนำเข้า **เครื่อง Media Player** ผ่านระบบคลังสินค้า ไม่มีการ "นำเข้าป้ายโฆษณา" ในหน้านี้ (ป้ายโฆษณาจัดการแยกในหมวด "ป้ายโฆษณา")
