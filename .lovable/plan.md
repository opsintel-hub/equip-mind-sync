# ปรับระบบกำหนดสิทธิ์ให้ไม่ซ้ำซ้อน

## ปัญหาปัจจุบัน
มี 3 มุมมอง (รายการผู้ใช้ / Matrix สิทธิ์ / แนวทางสิทธิ์) ที่ตั้งค่าทับกันได้ ทำให้ไม่รู้ว่า "ที่จริงควรตั้งตรงไหน" และเวลาคนหนึ่งต้องทำหลายหน้าที่ (รับเข้า + เบิก + จ่าย + อนุมัติ Swap) ไม่ชัดว่าเลือกอย่างไร

## แนวทางใหม่: 1 ที่ตั้งค่า + 1 ที่ดูภาพรวม + 1 ที่อ่าน

| มุมมอง | หน้าที่ใหม่ (ชัดเจน ไม่ทับกัน) |
|---|---|
| รายการผู้ใช้ (Wizard) | **ที่เดียวที่ใช้ตั้งค่ารายคน** — โปรไฟล์ + หน้าที่ + ฝ่าย/แผนก |
| Matrix สิทธิ์ | **ดูภาพรวม + ปรับหลายคนพร้อมกัน** เท่านั้น (ติดป้ายกำกับให้ชัด) |
| แนวทางสิทธิ์ | **คู่มืออ่านอย่างเดียว** อธิบายว่าแต่ละหน้าที่ทำอะไรได้ |

## หลักคิด: "หน้าที่งาน (Duty)" แทนการติ๊กเมนูทีละอัน
เลือกได้หลายหน้าที่ในคนเดียว ระบบรวมสิทธิ์ให้อัตโนมัติ:

- รับเข้า-คลัง (นำเข้า, รับเข้าคลัง, รอรหัส)
- เบิก-จ่าย (ขอเบิก, จ่ายของ, ยืนยันรับ, ส่งคืน)
- ของเสีย/ตัดจำหน่าย
- Swap / ประเมิน / เคลม
- ป้ายโฆษณา & PM
- ภาพโฆษณา
- ส่งตรง (Direct Shipping)
- ข้อมูลหลัก
- รายงาน & ตรวจสอบ
- **ผู้อนุมัติ** (แยกกล่องต่างหาก — ดูข้อ 2)

ตัวอย่างที่ถาม: คนที่ทำ "รับเข้า + เบิก + จ่าย + อนุมัติ Swap" = ติ๊ก 3 หน้าที่แรก + ติ๊ก "อนุมัติ Swap" ในกล่องผู้อนุมัติ จบในหน้าจอเดียว ถ้าต้องละเอียดกว่านั้น กดเปิด "ปรับละเอียด" เพื่อติ๊กรายเมนูเพิ่ม/ลดได้เหมือนเดิม

## 2. การกำหนด "ผู้อนุมัติ"
รวมสิทธิ์อนุมัติทั้งหมดไว้กล่องเดียวใน Wizard พร้อมคำอธิบายว่าอนุมัติเรื่องอะไรและกระทบใคร:
- อนุมัติเบิกทรัพย์สิน (Manager ของฝ่ายนั้น)
- อนุมัติของเสีย ชั้น 1 / ชั้น 2 / บัญชีรับทราบ
- อนุมัติส่งตรง
- จัดการ Swap (ฝั่งคลังเป็นผู้อนุมัติ/ดำเนินการ)

ผู้อนุมัติจะเห็นเฉพาะงานของ **ฝ่าย/แผนกที่ถูกกำหนดไว้** ในขั้นตอนเลือกฝ่าย ยกเว้นบัญชีรับทราบของเสียที่เห็นข้ามฝ่ายตามระบบเดิม

## 3. ตรวจความครบของเมนู
ไล่รายการเมนูในแถบข้างทั้งหมดเทียบกับรายการสิทธิ์ แล้วเติมสิทธิ์ที่ยังใช้ร่วมกันแบบหยาบให้แยกได้ถูกต้อง (เช่น เมนูที่ผูกกับ "รายงาน" และ "ข้อมูลหลัก" รวมกันหลายหน้า) พร้อมเพิ่มตัวช่วยเตือนใน Matrix ว่าสิทธิ์ตัวไหนยังไม่มีใครถือ

## รายละเอียดทางเทคนิค
- เพิ่มไฟล์ `src/lib/dutyPacks.ts` นิยามกลุ่มหน้าที่ (duty → รายชื่อ function) ใช้ร่วมกันทั้ง Wizard และ Matrix แทนการนิยามซ้ำสองที่
- `PermissionWizard.tsx`: ขั้นที่ 1 เปลี่ยนเป็นเลือก Duty แบบ multi-select + กล่อง "ผู้อนุมัติ" แยก + ส่วน "ปรับละเอียด" แบบพับเก็บ (คงตรรกะบันทึกเดิม: roles, user_function_permissions, user_departments, user_sections)
- `PermissionMatrix.tsx`: ใช้กลุ่มจาก `dutyPacks.ts`, เพิ่มคำอธิบายว่าโหมดนี้สำหรับปรับหลายคน และแถวสรุปจำนวนผู้ถือสิทธิ์ต่อ function
- `Admin.tsx`: ปรับข้อความกำกับ 3 มุมมองให้ชัดว่าตั้งค่าที่ไหน
- ไม่มีการแก้ schema ฐานข้อมูล ไม่กระทบสิทธิ์ที่ตั้งไว้แล้ว
