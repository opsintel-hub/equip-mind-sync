# นำเข้ารูปจำนวนมากแบบจับคู่อัตโนมัติด้วย S/N

## สิ่งที่จะได้

หน้าใหม่ "นำเข้ารูปภาพจำนวนมาก" ในกลุ่มนำเข้าข้อมูลเริ่มต้น สำหรับ Media Player/จอภาพ และเครื่องมือ

1. เลือกประเภท: Media Player/จอภาพ หรือ เครื่องมือ
2. เลือกรูปทีเดียวได้ทั้งโฟลเดอร์ (ลากวาง หรือกดเลือกโฟลเดอร์)
3. ระบบอ่านชื่อไฟล์ ตัดนามสกุลและลำดับท้ายชื่อออก แล้วจับคู่กับ S/N ในระบบ
   - `SN12345.jpg` → เครื่องที่มี S/N 1 หรือ S/N 2 = SN12345
   - `SN12345_1.jpg`, `SN12345_2.jpg` → เครื่องเดียวกัน รูปแรกเป็นรูปหลัก
   - รองรับตัวคั่น `_1` `-1` ` (1)` และไม่สนตัวพิมพ์เล็ก/ใหญ่
4. แสดงตารางตรวจก่อนอัปโหลด: จับคู่ได้กี่ไฟล์ / ไม่พบ S/N / S/N ซ้ำหลายเครื่อง / ไฟล์ใหญ่เกิน 10MB / เครื่องนั้นมีรูปครบ 5 รูปแล้ว
5. กด "เริ่มอัปโหลด" — ทำทีละชุด (batch 5 ไฟล์) มีแถบความคืบหน้า หยุดกลางคันได้ และอัปโหลดซ้ำไฟล์ที่ค้างได้โดยไม่สร้างรูปซ้ำ
6. จบแล้วดาวน์โหลดสรุปผลเป็น Excel (ไฟล์ไหนเข้าเครื่องไหน ไฟล์ไหนไม่เข้าและเพราะอะไร)

ระหว่างอัปโหลดระบบจะย่อรูปในเครื่องก่อน (ด้านยาวสุด 1600px, JPEG คุณภาพ 80%) ทำให้เกือบพันรูปอัปโหลดเร็วขึ้นมากและประหยัดพื้นที่เก็บ

## รูปที่อยู่บน Google Drive

วิธีที่ประหยัดและเร็วที่สุดคือ **ซิงก์ลงเครื่องก่อน** แล้วใช้หน้านี้อัปโหลดทั้งโฟลเดอร์:
ติดตั้ง Google Drive for desktop → คลิกขวาโฟลเดอร์รูป → Offline access → Available offline → โฟลเดอร์จะอยู่ในเครื่องจริง แล้วลากเข้าหน้าอัปโหลดได้เลย

การต่อ Google Drive เข้าระบบโดยตรงก็ทำได้ แต่ต้องตั้งค่าการเชื่อมต่อเพิ่มและใช้เครดิตมากกว่าโดยไม่ได้เร็วขึ้น จึงไม่แนะนำสำหรับงานย้ายข้อมูลครั้งเดียว ถ้าภายหลังต้องดึงรูปจาก Drive เป็นประจำ ค่อยเพิ่มทีหลังได้

## เตรียมชื่อไฟล์ให้พร้อม (ทำครั้งเดียว ไม่เสียเครดิต)

ถ้าชื่อไฟล์ยังไม่ใช่ S/N สามารถทำไฟล์ Excel 2 คอลัมน์ (ชื่อไฟล์เดิม, S/N) แล้วใช้คำสั่งเปลี่ยนชื่อไฟล์ทีเดียวบน Windows ผมเตรียมสคริปต์ให้ได้ถ้าต้องการ

## เรื่องรูป 3D หมุน-ซูมดู S/N

ทำได้ 3 แนวทาง:

| แนวทาง | ผลลัพธ์ | ต้นทุนต่อเครื่อง |
|---|---|---|
| ซูมรูปความละเอียดสูง | ลากเลื่อน/ซูมดูเลข S/N ได้ชัด ไม่หมุนรอบตัว | แทบไม่มี — แค่ถ่ายรูปชัด ๆ |
| 360° แบบภาพต่อเนื่อง | ลากเมาส์แล้วหมุนรอบตัวได้จริง | ถ่าย 24–36 รูปต่อเครื่อง |
| โมเดล 3D จริง (glb) | หมุน/ซูมได้ทุกมุม | สแกน/ทำโมเดลต่อรุ่น |

ข้อเสนอที่คุ้มที่สุดสำหรับเกือบพันเครื่อง: ใช้ **ซูมรูปความละเอียดสูง** เป็นหลัก (เพิ่มการซูมในหน้าดูรูปเดิม ต้นทุนต่ำ ใช้รูปที่มีอยู่ได้เลย) และทำ **360°** เฉพาะรุ่นตัวแทน ไม่ใช่ทุกเครื่อง เพราะเครื่องรุ่นเดียวกันหน้าตาเหมือนกัน ต่างแค่เลข S/N ซึ่งอ่านจากรูปซูมได้อยู่แล้ว

ในแผนนี้ผมจะทำเฉพาะ **ระบบนำเข้ารูปอัตโนมัติ** ก่อน ส่วน 3D/360° แยกทำทีหลังเมื่อคุณตัดสินใจ

## รายละเอียดทางเทคนิค

- หน้าใหม่ `src/pages/setup/ImportImagesPage.tsx` + route ใน `App.tsx` + เมนูใต้กลุ่มนำเข้าข้อมูลเริ่มต้น (สิทธิ์เดียวกับหน้านำเข้าอื่น)
- ตัวจับคู่ `src/lib/importTemplates/imageMatcher.ts`: normalize ชื่อไฟล์ (trim, upper, ตัด `_\d+` / `-\d+` / ` (\d+)` ท้ายชื่อ), map จาก `media_players.serial_number_1|serial_number_2` และ `tools.serial_number` → fallback `tools.code`
- อัปโหลดเข้า bucket เดิม `media-player-images` / `tool-images`, เขียนแถวลง `media_player_images` / `tool_images` พร้อม `display_order` ตามลำดับท้ายชื่อ และตั้ง `is_primary` ให้รูปแรกเมื่อเครื่องนั้นยังไม่มีรูปหลัก
- เคารพเพดานรูปเดิม (MP 5 รูป, เครื่องมือ 4 รูป) และข้ามไฟล์ชื่อซ้ำที่อัปโหลดไปแล้ว (เก็บ hash ชื่อไฟล์ใน path)
- ย่อรูปฝั่งเบราว์เซอร์ด้วย canvas ก่อนอัปโหลด, ทำทีละ 5 ไฟล์พร้อม yield ให้ UI ไม่ค้าง
- สรุปผลส่งออกด้วย `xlsx` เหมือนหน้านำเข้าอื่น
