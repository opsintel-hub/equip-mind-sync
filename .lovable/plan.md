
# แผนการปรับปรุงหน้า "รับสินค้าเข้าคลัง"

## สรุปปัญหาปัจจุบัน
เมื่อผู้ใช้ (เจ้าหน้าที่คลัง) คลิกเข้าไปดูรายการสินค้าที่รอรับเข้า และพบว่าเป็น **สินค้าใหม่** ที่ยังไม่มีในระบบ ปัจจุบันต้อง:
1. ปิด Dialog "รับเข้าคลัง" ออกมา
2. กดปุ่ม "+เพิ่มอุปกรณ์" ที่มุมบนขวา
3. กรอกข้อมูลสินค้าใหม่ด้วยตัวเอง (ไม่มี auto-fill)
4. กลับมาเปิด Dialog รับเข้าใหม่อีกครั้ง

## วิธีแก้ไข
เพิ่มปุ่ม **"+เพิ่มอุปกรณ์"** ไว้ภายใน Dialog รับเข้าสินค้าเลย พร้อมระบบ **Auto-fill** ข้อมูลจากรายการที่กำลังรับเข้า

---

## ขั้นตอนการทำงาน

### 1. ปรับปรุง EquipmentForm ให้รองรับ Prefill Data
- เพิ่ม Props ใหม่ `prefillData` สำหรับรับข้อมูลที่จะกรอกอัตโนมัติ
- เพิ่ม Props `triggerButton` เพื่อให้สามารถ customize ปุ่มเปิด Dialog ได้
- ข้อมูลที่จะ auto-fill ได้แก่:
  - ชื่อสินค้า (`equipment_name`)
  - หน่วย (`unit`)
  - Serial Number (`serial_number`)
  - วันหมดอายุ (`expiry_date`)
  - วันหมดรับประกัน (`warranty_expiry_date`)
  - หมายเหตุ (`notes`)

### 2. เพิ่มปุ่ม "+เพิ่มอุปกรณ์" ใน Dialog รับเข้าสินค้า
- แสดงปุ่มเมื่อรายการนั้น **ไม่มี equipment_id** (เป็นสินค้าใหม่)
- วางปุ่มในตำแหน่งที่เหมาะสมใกล้กับข้อมูลสินค้า
- เมื่อกด จะเปิด EquipmentForm พร้อมข้อมูลที่ถูกกรอกไว้แล้ว

### 3. เชื่อมต่อ Callback หลังสร้างสินค้าสำเร็จ
- หลังสร้างสินค้าใหม่สำเร็จ ระบบจะ:
  - Refresh ข้อมูล equipment list
  - อัปเดต `goods_receipt_pending` record ให้ผูกกับ equipment_id ใหม่
  - แจ้งผู้ใช้ว่าสามารถกด "รับเข้าคลัง" ได้ทันที

---

## ผลลัพธ์ที่คาดหวัง
- ผู้ใช้สามารถสร้างสินค้าใหม่ได้โดย **ไม่ต้องออกจาก Dialog**
- ข้อมูลจากการนำเข้า (ชื่อ, หน่วย, Serial, วันหมดอายุ) ถูก **กรอกให้อัตโนมัติ**
- หลังสร้างเสร็จ สามารถกด **"รับเข้าคลัง"** ได้ทันที

---

## รายละเอียดทางเทคนิค

### ไฟล์ที่ต้องแก้ไข

**1. `src/components/equipment/EquipmentForm.tsx`**
- เพิ่ม interface `PrefillData` สำหรับรับข้อมูล
- เพิ่ม Props:
  ```typescript
  interface EquipmentFormProps {
    onSuccess?: (newEquipmentId?: string) => void;
    prefillData?: {
      name?: string;
      unit?: string;
      serial_number?: string;
      expiry_date?: string;
      warranty_expiry_date?: string;
      notes?: string;
      quantity?: number;
    };
    triggerButton?: React.ReactNode;
  }
  ```
- ใช้ `useEffect` เพื่อ set form values เมื่อ `prefillData` เปลี่ยน
- Callback `onSuccess` ส่ง `equipmentId` กลับไปให้ใช้อัปเดต pending receipt

**2. `src/pages/ReceiveGoods.tsx`**
- เพิ่ม state `isEquipmentFormOpen` และ logic สำหรับ nested dialog
- ในส่วนที่แสดง "ชื่อสินค้า" ของ Dialog รับเข้า:
  - เพิ่มปุ่ม "+สร้างอุปกรณ์ใหม่" เมื่อ `!selectedReceipt.equipment_id`
- เพิ่ม function `handleEquipmentCreated` ที่จะ:
  - อัปเดต `goods_receipt_pending.equipment_id` ให้ชี้ไปยัง equipment ใหม่
  - Refresh pending receipts
  - แจ้งผู้ใช้ว่าพร้อมรับเข้าคลังแล้ว

### การแสดงผล

ใน Dialog รับเข้าสินค้า จะมีลักษณะดังนี้:

```
┌───────────────────────────────────────────────────────┐
│ รับสินค้าเข้าคลัง                                        │
├───────────────────────────────────────────────────────┤
│                                                       │
│ ชื่อสินค้า                                               │
│ ┌─────────────────────────────────────────┐ ┌───────┐│
│ │ สายไฟ 2x4                              │ │ดูภาพ  ││
│ └─────────────────────────────────────────┘ └───────┘│
│                                                       │
│ ⚠️ สินค้าใหม่ยังไม่มีในระบบ                              │
│ ┌────────────────────────────────────────────────────┐│
│ │ ➕ สร้างอุปกรณ์ใหม่ (Auto-fill จากข้อมูลนำเข้า)       ││
│ └────────────────────────────────────────────────────┘│
│                                                       │
│ ... (ข้อมูลอื่นๆ)                                        │
│                                                       │
│              [ยกเลิก]  [รับเข้าคลัง]                      │
└───────────────────────────────────────────────────────┘
```

เมื่อกดปุ่ม "สร้างอุปกรณ์ใหม่" จะเปิด Form ใหม่ที่มีข้อมูลกรอกไว้แล้ว:
- ชื่อสินค้า: "สายไฟ 2x4"
- หน่วย: "เมตร"
- Serial Number: "SN-12345"
- วันหมดอายุ: "31/12/2026"
