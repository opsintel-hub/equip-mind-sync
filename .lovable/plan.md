# กำหนดสิทธิ์ที่เดียว: 7 ระดับผู้ใช้

## ปัญหา
ตอนนี้ตั้งสิทธิ์ได้ 3 ที่ที่ทับซ้อนกัน: หน้าต่างเก่า (แท็บ บทบาท/ฟังก์ชัน/ฝ่าย), มุมมอง Matrix สิทธิ์ และ Wizard ทำให้ผู้ใช้สับสนและตรวจสอบยาก

## สิ่งที่จะทำ
เหลือ **ที่เดียว** คือ Wizard และเปลี่ยนขั้นแรกเป็นการเลือก "ระดับผู้ใช้" 7 แบบ

| ระดับ | เมนูที่ได้ | ฝ่าย |
|---|---|---|
| 1. Super Admin | ทุกเมนู รวมจัดการผู้ใช้ นำเข้าข้อมูลเริ่มต้น ทดสอบระบบ คู่มือ | ทุกฝ่าย |
| 2. Admin | ทุกเมนูงาน ยกเว้น 4 เรื่องที่สงวนให้ Super Admin | ทุกฝ่าย/ทุกคลัง เสมอ (ไม่ต้องเลือก) |
| 3. เจ้าหน้าที่คลัง | รับเข้า, เบิก-จ่าย, โอนย้าย, ของเสีย, งาน Swap/ประเมิน/เคลม, ข้อมูลหลักคลัง, รายงาน | เลือกได้หลายฝ่าย |
| 4. ผู้อนุมัติ | อนุมัติเบิกทรัพย์สิน, อนุมัติส่งตรง, อนุมัติของเสียชั้น 1-2, อนุมัติ Swap + ดูรายงาน | เลือกได้หลายฝ่าย |
| 5. ผู้ใช้งานทั่วไป | ขอนำเข้า, ขอเบิก, ขอส่งตรง, ติดตามคำขอของตัวเอง | เลือกได้หลายฝ่าย |
| 6. ผู้ใช้ภาพโฆษณา | นำเข้าภาพ, ขอเบิกภาพ, คลังภาพ, ข้อมูลป้าย, จัดแพ็กป้าย | เลือกได้หลายฝ่าย |
| 7. บัญชี & จัดซื้อ | รายงานทุกหน้า, Stock Card, KPI, ค้นหาเอกสาร, บัญชีรับทราบของเสีย (ดูอย่างเดียว) | เลือกได้หลายฝ่าย |

ทุกระดับตั้งมาจาก "หน้าที่งาน" เดิมที่มีอยู่แล้ว จึงไม่กระทบสิทธิ์ที่ตั้งไว้ของผู้ใช้ปัจจุบัน

## หน้าตาการใช้งาน
- **ขั้น 1** เลือกระดับผู้ใช้ 1 ใน 7 (การ์ดพร้อมคำอธิบายและรายการเมนูที่จะได้) — ปุ่ม "ปรับละเอียด" ซ่อนไว้ ถ้ากดจึงเปิดให้ติ๊กเพิ่ม/ลดรายเมนูเป็นกรณีพิเศษ พร้อมป้าย "ปรับแต่งเอง" กำกับ
- **ขั้น 2** เลือกฝ่าย/แผนก — ระดับ 3-7 บังคับเลือกอย่างน้อย 1 ฝ่าย, ระดับ 1-2 ข้ามขั้นนี้พร้อมข้อความว่าเห็นทุกฝ่าย
- **ขั้น 3** สรุปตรวจสอบ: ระดับ, รายการเมนูจัดกลุ่มตามแถบเมนูจริง, ฝ่ายที่เห็น
- หน้ารายการผู้ใช้แสดงป้ายระดับผู้ใช้ (1 ป้ายต่อคน) ให้ตรวจสอบภาพรวมได้ทันที และกรองตามระดับได้
- ลบหน้าต่างตั้งสิทธิ์เก่า (แท็บ บทบาท/ฟังก์ชัน/ฝ่าย) และลบมุมมอง "Matrix สิทธิ์" ออก เหลือ 2 มุมมอง: รายการผู้ใช้ และ แนวทางสิทธิ์
- หน้าแนวทางสิทธิ์อัปเดตคำอธิบายให้ตรงกับ 7 ระดับ

## รายละเอียดทางเทคนิค
- `src/lib/dutyPacks.ts`: เพิ่ม `ACCESS_LEVELS` (key, label, description, roles, fns, deptMode: "all" | "select") ประกอบจาก `DUTY_PACKS`/`APPROVAL_PERMISSIONS` เดิม + helper `detectAccessLevel(roles, fns)` สำหรับแสดงป้ายและ pre-select ตอนเปิด Wizard
- `PermissionWizard.tsx`: แทน state `accessLevel` แบบ 3 ค่า ด้วย key จาก `ACCESS_LEVELS`; เลือกระดับ → ตั้ง `previewFunctions`/`previewRoles` จาก preset; "ปรับละเอียด" = collapsible ที่ยังใช้ `GROUPED_FUNCTIONS` เดิม; ขั้น 2 ข้ามเมื่อ `deptMode === "all"`; `handleSave` เขียน `save_user_roles` + `user_function_permissions` + `user_departments`/`user_sections` เหมือนเดิม (ระดับ 1-2 ล้าง `user_departments` ทิ้ง เพราะเห็นทุกฝ่ายจาก role)
- `useDepartmentPermissions.tsx`: ให้ `isAdmin` (admin + super_admin) คืนทุกฝ่ายใน `getViewableDepartments` และผ่าน `hasPermission` เหมือน Super Admin — คงการสงวน 4 ฟังก์ชันไว้ที่ `useFunctionPermissions` เท่านั้น
- `UserPermissionManager.tsx`: ลบ Main Permission Dialog (แท็บ roles/functions/departments ~บรรทัด 917-1167) กับ state/handler ที่เกี่ยวข้อง, เพิ่มคอลัมน์ป้ายระดับผู้ใช้จาก `detectAccessLevel`
- `Admin.tsx`: ลบตัวเลือกมุมมอง Matrix; ลบไฟล์ `PermissionMatrix.tsx` และ `QuickPresetSelector.tsx` ถ้าไม่มีที่อื่นเรียกใช้
- `RoleDescriptions.tsx` / `FunctionDescriptions.tsx`: อธิบาย 7 ระดับใหม่
- ไม่แก้โครงสร้างฐานข้อมูล
