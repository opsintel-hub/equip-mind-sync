
# ปัญหา

Template Excel ของ **Import Excel** (หน้า ข้อมูลหลัก → คลัง & ตำแหน่งจัดเก็บ) ยังเป็นเวอร์ชันเก่า ไม่ตรงกับ UI ปัจจุบัน ทำให้:

1. **ไม่มีคอลัมน์ขนาด (กว้าง/สูง/ลึก cm)** → นำเข้าเสร็จแล้วทุกตำแหน่งเป็น `0.00 / 0.00 m³` (ตามภาพ)
2. **ไม่มีทางกำหนดฝ่าย (department) และ ประเภทพื้นที่ ของคลัง** → คลังโชว์ `ไม่ระบุฝ่าย` เพราะไม่มีตัวจัดการที่ระดับคลังในไฟล์นำเข้า ผู้ใช้ต้องมานั่งแก้ทีละคลัง
3. **ผลลัพธ์หลังนำเข้าไม่บอกว่า import เข้าไปในคลังไหนบ้าง** → เห็นแค่ตัวเลขรวม success/failed ไม่รู้ว่าเข้าคลังใด กี่รายการ

# ขอบเขตงาน

แก้เฉพาะไฟล์ที่เกี่ยวข้องกับการ Import — ไม่แตะ logic การแสดงผลรายการหรือฐานข้อมูล

## 1. ปรับ Template `LocationImport` (`src/components/location/LocationImport.tsx`)

เพิ่มคอลัมน์ให้ครบตามที่ `LocationForm` บันทึกได้:

| คอลัมน์เดิม | คอลัมน์ใหม่ที่เพิ่ม |
|---|---|
| รหัสตำแหน่ง* | กว้าง (cm) |
| ชื่อตำแหน่ง* | สูง (cm) |
| รายละเอียด | ลึก (cm) |
| พื้นที่จัดเก็บ | *volume คำนวณอัตโนมัติจาก กว้าง×สูง×ลึก* |
| รหัสคลังสินค้า* | |
| รหัสโซน / ชื่อโซน | |

- อ่านค่าตัวเลขเป็น number → คำนวณ `volume_cm3 = w*h*d` อัตโนมัติเมื่อครบทั้ง 3 ค่า
- Template ตัวอย่างใส่ค่า sample ให้ดู เช่น `60 / 40 / 40`
- ปรับ column widths ให้ครอบคลุมคอลัมน์ใหม่

## 2. เพิ่ม Warehouse Import (ไฟล์ใหม่ `src/components/warehouse/WarehouseImport.tsx`)

Template มีคอลัมน์:
- รหัสคลัง* / ชื่อคลัง* / ประเภทพื้นที่ (Indoor/Outdoor/Semi-outdoor)* / ฝ่าย / รายละเอียด

Logic:
- Upsert ตาม `code` (มีอยู่แล้ว → update, ยังไม่มี → insert)
- ฟิลด์ `department` เขียนเป็น **text ชื่อฝ่าย** (ตรงกับ schema ปัจจุบันของ `warehouses.department`)
- Validate `storage_area` ว่าอยู่ใน 3 ค่าที่อนุญาต

วางปุ่ม `Import คลัง` ไว้ข้างปุ่ม `Import Excel` (ที่มีอยู่) ใน `WarehouseLocationAccordion.tsx` ให้ผู้ใช้เลือกได้ทั้ง 2 แบบ

## 3. ปรับผลลัพธ์หลังนำเข้าใน `LocationImport`

- แสดงสรุปเป็นตาราง/รายการ: `รหัสคลัง — ชื่อคลัง : เพิ่มใหม่ X, อัปเดต Y`
- เก็บ counter แยกตาม warehouse_code ระหว่างวน loop
- Errors เดิมคงไว้

## เทคนิค

- ยังใช้ `xlsx` เดิม, pattern เดียวกับ `LocationImport` และ `SupplierImport`
- ไม่ต้อง migration DB — ทุก field มีอยู่แล้ว
- ไม่แตะ `LocationForm` / `WarehouseForm` / RLS

# ผลลัพธ์ที่ผู้ใช้จะเห็น

- ดาวน์โหลด Template Excel ใหม่ → กรอกขนาดกว้าง/สูง/ลึกได้ → นำเข้าแล้วเห็น m³ ทันที
- มี Template คลังแยก → ผู้ใช้ระบุฝ่าย + ประเภทพื้นที่ในไฟล์เดียวได้ ไม่ต้องมาคลิกทีละคลัง
- สรุปผลนำเข้าบอกว่าไปเข้าที่คลังไหนบ้าง
