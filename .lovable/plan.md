
# แผนการพัฒนา: เพิ่มหน้าจัดการหมวดหมู่และหมวดหมู่ย่อยใน Master Data

## สรุปภาพรวม
เพิ่มแท็บ **"หมวดหมู่"** ใน Master Data เพื่อให้ผู้ใช้สามารถ:
- ดูภาพรวมหมวดหมู่หลักและหมวดหมู่ย่อยทั้งหมด
- สร้าง/แก้ไข/ลบ หมวดหมู่หลัก
- สร้าง/แก้ไข/ลบ หมวดหมู่ย่อย พร้อมผูกกับหมวดหมู่หลัก
- ช่องในฟอร์มอุปกรณ์ยังคงเป็น Dropdown พร้อมปุ่ม Settings เพิ่มด่วน

## ส่วนที่ 2: สร้าง Component ใหม่

### 2.1 CategoryList.tsx - รายการหมวดหมู่หลัก
แสดงตารางหมวดหมู่หลักพร้อม:
- ชื่อหมวดหมู่
- คำอธิบาย
- จำนวนหมวดหมู่ย่อย (Badge)
- ปุ่มแก้ไข/ลบ

### 2.2 CategoryForm.tsx - ฟอร์มเพิ่ม/แก้ไขหมวดหมู่หลัก
Dialog สำหรับ:
- ชื่อหมวดหมู่ *
- คำอธิบาย (ไม่บังคับ)

### 2.3 SubcategoryList.tsx - รายการหมวดหมู่ย่อย
แสดงตารางหมวดหมู่ย่อยพร้อม:
- ชื่อหมวดหมู่ย่อย
- หมวดหมู่หลัก (Badge)
- คำอธิบาย
- ปุ่มแก้ไข/ลบ
- ตัวกรองตามหมวดหมู่หลัก

### 2.4 SubcategoryForm.tsx - ฟอร์มเพิ่ม/แก้ไขหมวดหมู่ย่อย
Dialog สำหรับ:
- หมวดหมู่หลัก * (Dropdown)
- ชื่อหมวดหมู่ย่อย *
- คำอธิบาย (ไม่บังคับ)

## ส่วนที่ 4: รายละเอียดทางเทคนิค

### 4.1 ไฟล์ใหม่ที่ต้องสร้าง
| ไฟล์ | หน้าที่ |
|------|--------|
| `src/components/category/CategoryList.tsx` | แสดงรายการหมวดหมู่หลัก |
| `src/components/category/CategoryForm.tsx` | Dialog เพิ่ม/แก้ไขหมวดหมู่หลัก |
| `src/components/category/SubcategoryList.tsx` | แสดงรายการหมวดหมู่ย่อย |
| `src/components/category/SubcategoryForm.tsx` | Dialog เพิ่ม/แก้ไขหมวดหมู่ย่อย |

### 4.2 ไฟล์ที่ต้องแก้ไข
| ไฟล์ | การเปลี่ยนแปลง |
|------|---------------|
| `src/pages/MasterData.tsx` | เพิ่มแท็บ "หมวดหมู่" |

### 4.3 ไม่ต้องแก้ไขฐานข้อมูล
ตาราง `categories` และ `subcategories` มีอยู่แล้วพร้อมความสัมพันธ์:
- `categories`: id, name, description, is_active
- `subcategories`: id, **category_id** (FK), name, description, is_active

### 4.4 ช่องเดิมในฟอร์มอุปกรณ์
ยังคงทำงานเหมือนเดิม:
- Dropdown หมวดหมู่หลัก พร้อมปุ่ม Settings (เพิ่มด่วน)
- Dropdown หมวดหมู่ย่อย กรองตามหมวดหมู่หลัก พร้อมปุ่ม Settings

## ส่วนที่ 5: ขั้นตอนการดำเนินงาน

1. **สร้าง CategoryList.tsx** - แสดงรายการหมวดหมู่หลักพร้อม CRUD
2. **สร้าง CategoryForm.tsx** - Dialog เพิ่ม/แก้ไข
3. **สร้าง SubcategoryList.tsx** - แสดงรายการหมวดหมู่ย่อยพร้อม CRUD และตัวกรอง
4. **สร้าง SubcategoryForm.tsx** - Dialog เพิ่ม/แก้ไขพร้อมเลือกหมวดหมู่หลัก
5. **อัปเดต MasterData.tsx** - เพิ่มแท็บใหม่
6. **ทดสอบ** - ตรวจสอบการทำงานทั้งหมด

## ประโยชน์ที่จะได้รับ

- มองเห็นภาพรวมหมวดหมู่ทั้งหมดได้ง่าย
- จัดการหมวดหมู่ได้เยอะๆ พร้อมกัน ไม่ต้องผ่านฟอร์มอุปกรณ์
- เห็นความสัมพันธ์ระหว่างหมวดหมู่หลักและย่อยชัดเจน
- สอดคล้องกับการผูกวัตถุประสงค์เบิกกับหมวดหมู่ที่เพิ่งทำไป
- ยังคงใช้ปุ่ม Settings ในฟอร์มอุปกรณ์สำหรับเพิ่มด่วนได้
