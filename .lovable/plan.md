## เป้าหมาย
ปรับ layout การพิมพ์ QR Code ของ Media Player ให้ตรงตามภาพตัวอย่างที่ส่งมา (สติกเกอร์ "R16" + QR + เส้นคั่น + "DS-086 SN.KSA7918411")

## สิ่งที่จะแก้
ไฟล์: `src/components/media-player/profile/ProfileHeader.tsx` (ฟังก์ชัน `printQR`)

### Layout ใหม่
```text
┌─────────────────────────────────┐
│                    ┌─────────┐  │
│   R16              │ ▓▓▓ QR ▓│  │
│  (ใหญ่ มาก)         │ ▓▓▓▓▓▓▓│  │
│                    └─────────┘  │
│ ───────────────────────────────  │
│      DS-086  SN.KSA7918411      │
└─────────────────────────────────┘
```

### การเปลี่ยนแปลงเทียบของเดิม
- **บรรทัดบน (ซ้าย)**: Remote Name ตัวใหญ่ (เหมือนเดิม "R16")
- **บรรทัดบน (ขวา)**: QR Code (เหมือนเดิม)
- **เส้นคั่นแนวนอน**: เพิ่มเส้นใต้ทั้งสองส่วน เต็มความกว้าง (`border-top: 2px solid #000`)
- **บรรทัดล่าง (กลาง)**: แสดง `{code}` เว้นวรรค `SN.{serial_number_1}` ใน 1 บรรทัดเดียว จัดกึ่งกลาง
  - ตัวอย่าง: `DS-086  SN.KSA7918411`
  - ตัด Model ออก (ไม่มีในภาพตัวอย่าง)
  - ตัด divider แนวตั้งสีน้ำเงินออก
- ใช้ฟอนต์ตัวหนา ขนาดใหญ่พอ (~28-32px) เพื่อให้อ่านชัดบนสติกเกอร์

### ตัวอย่างผลลัพธ์ (preview HTML ใน print window)
- `R16` ขนาด ~96px ชิดซ้าย, QR ~180px ชิดขวา
- เส้นดำคั่น
- `DS-086 SN.KSA7918411` กึ่งกลาง ขนาด ~28px ตัวหนา

ส่วน UI ในแอพ (Dialog QR Code) คงเดิม ไม่แตะ
